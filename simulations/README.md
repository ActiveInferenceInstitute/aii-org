# Interactive Simulations — Active Inference Institute

A curated collection of 12 interactive, browser-based standalone simulations demonstrating the core concepts of the Free Energy Principle and Active Inference.

## Catalogue

### Beginner
| File | Name | Key Concepts |
|------|------|--------------|
| `Ink.html` | Life Emerges – Living Ink | Free Energy, Self-Organisation, Markov Blanket |
| `Apple-Frog.html` | Apple or Frog? | Bayesian Inference, Prior Beliefs |
| `fep_surprise.html` | Surprise Minimisation | Prediction Error, Belief Updating |
| `school6.html` | Fish Schooling | Collective Agency, Generalised Synchrony |

### Intermediate
| File | Name | Key Concepts |
|------|------|--------------|
| `fep_tutorial.html` | From Beliefs to Action | Generative Model, VFE, EFE |
| `self_evidencing_tree.html` | The Self-Evidencing Tree | Morphogenesis, Prior Preferences |
| `ant_colony.html` | Active InferAnts | Stigmergy, Niche Construction |
| `active_inference_network.html` | Active Inference Network | Markov Blankets, Collective Autonomy |

### Advanced
| File | Name | Key Concepts |
|------|------|--------------|
| `t_maze_fep.html` | T-Maze (FEP) | Expected Free Energy, POMDP |
| `dopamine_daniel.html` | The Dopamine Dial | Neuromodulation, DA:5-HT Ratio |
| `hierarchical_blankets.html` | Hierarchical Markov Blankets | Nested Systems, Hierarchy |
| `tree_with_quiz.html` | Tree Morphology Quiz | Precision, Prior Preferences, Hierarchy, Bounded Rationality, Markov Blankets |
