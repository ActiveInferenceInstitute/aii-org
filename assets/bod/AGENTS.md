# AGENTS.md — Board of Directors Headshots

## Purpose

Archived headshot photographs for the 10 Board of Directors members. `pages/bod.html` no longer renders portraits; it links the canonical membership roster maintained by the Institute registry.

## Conventions

- Format: JPEG (`.jpg`)
- Naming: `firstname_lastname.jpg` (lowercase, underscores)
- Archived: no page currently references these files. If a page renders headshots again, reference them as `src="../assets/bod/firstname_lastname.jpg"` with descriptive `alt` text and `loading="lazy"`
- Images are square or near-square, suitable for CSS `object-fit: cover` at small display sizes
